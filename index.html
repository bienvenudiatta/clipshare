💡 Comment ça marche
  1. Ouvre cette page sur 2 appareils (téléphone + PC)
  2. Sur l'appareil A, note le code de salle
  3. Sur l'appareil B, entre ce code et clique Rejoindre
  4. Colle du texte d'un côté → il arrive de l'autre côté

Fonctionne en peer-to-peer — rien ne passe par un serveur. 🔒
